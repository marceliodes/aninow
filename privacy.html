Plain-language policy

Privacy

AniNow is designed to work without collecting a personal anime profile.

What AniNow does not have

There are no accounts, sign-in forms, comments, persistent favorites, first-party analytics, advertising trackers, or required cookies. AniNow does not ask you to submit personal information.

Theme preference

If you use the theme switcher, the choice is stored in sessionStorage. It lasts only for the current browser tab session. AniNow does not use localStorage.

Requests made while you browse

The site’s JavaScript requests anime data only from same-origin /api/… endpoints. Those server-side endpoints contact the official MyAnimeList API using a server-only Client ID. Cover artwork is loaded directly from MyAnimeList’s image host, so that host receives a normal image request from your browser.

External links

A title’s MyAnimeList page opens only when you choose its external link. External sites have their own privacy practices.

This page describes the V1 implementation as shipped. It should be revised if analytics, accounts, or other data collection is added later.
